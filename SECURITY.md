# Reportar uma vulnerabilidade

Não abra uma issue pública com credenciais, dados privados ou detalhes exploráveis de uma vulnerabilidade.

Use o recurso **Report a vulnerability** na aba Security deste repositório para enviar o relato privadamente. Se o recurso não estiver disponível, peça contato privado ao mantenedor sem publicar detalhes sensíveis.

O projeto ainda está em fase de arquitetura e não possui uma versão estável. Relatos sobre exposição de credenciais, execução arbitrária de comandos, associação incorreta entre jobs e threads ou retomadas duplicadas são especialmente relevantes.
